# Project vault contract

The root `../AGENTS.md` still applies. This file adds only what is specific to
project pages.

## Read

- Before working on a project, `<name>.md` here. Not a neighbouring page that
  mentions it, and not the root index.
- Before adding a project, `_template.md`.

## Write

- The page owns where the repo is, which branch is real, where tickets live, how
  it deploys, and how you know it is live.
- Update it when any of those moves. A page that describes a setup which no
  longer exists is worse than none.
- Record what the repo does not say: the reason behind a choice, the convention,
  the gotcha. `git remote -v` already states the remotes.
- Mark judgment as judgment, and label inference, so a later session re-checks
  it.

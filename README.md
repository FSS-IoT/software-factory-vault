# The software factory vault

The seed for a working method: how to take an idea to something running with
agents, and the vault they use to remember it.

Clone it, point an agent at it, and it installs itself.

## Install

From any folder, tell your agent:

> Clone `<this repo>` and set up the software factory for me.

It asks three questions, writes one line into your harness's instruction file, and
proves the install from a different folder. There is nothing else to configure:
no packages, no accounts, no service.

If you would rather read before installing, open `START-HERE.md`.

## This is the seed, not your copy

Copy it into your own store and edit it freely. Your copy is the source of truth
from that moment on; this repository only provides the starting point.

That is deliberate. A vault collects preferences that are personal, so it drifts.
When a change is worth sharing, it comes back here as a diff, not as a
replacement of your copy.

## Who it is for

People who can run an agent and have an idea, but have never written software.
The method assumes no stack, no operating system and no particular harness.

Taught as a class. The slides are at
[FSS-IoT/software-factory](https://github.com/FSS-IoT/software-factory).
